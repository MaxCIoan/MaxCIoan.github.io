# Maximilian Cozzone Portfolio

Static GitHub Pages landing page for reviewing cybersecurity, IT support, networking, and Python projects.

## Files

- `index.html` - main portfolio landing page
- `resume.html` - styled resume page copied from the Desktop `Resume` folder

## Publish With GitHub Pages

1. Create a public GitHub repository named `MaxCIoan.github.io`.
2. Upload `index.html`, `resume.html`, and this `README.md` to the repository root.
3. Open the repository settings.
4. Go to `Pages`.
5. Set the source to the `main` branch and root folder.
6. After GitHub finishes publishing, open `https://MaxCIoan.github.io`.
