Project Passports

Each passport explains why the project exists, how well I understand it, and what mistakes improved the work.

🛡️ HIDS-Project

Strongest project
Goal

Build a Bash-based host intrusion detection lab that checks system health, files, services, processes, users, logs, and reports alerts clearly.

Learning

Linux monitoring, shell scripting structure, baseline comparison, alert logic, log formatting, and how SOC-style checks need repeatable output.

Strength

I am most comfortable explaining this project because it connects directly to blue-team work: observe, compare, document, alert, and escalate.

Mistakes

I learned to avoid noisy checks, unclear report wording, and scripts that only work in one folder. Cleaner output made the project easier to review.

🐍 Python-Port-Scanner

High confidence
Goal

Create a scanner to practice TCP/IP fundamentals, ports, services, socket behavior, and basic enumeration thinking.

Learning

Python sockets, connection timeouts, scan ranges, input validation, error handling, and why scan results need careful interpretation.

Strength

I can explain the security purpose, the networking basics behind it, and where tools like Nmap become more powerful in real operations.

Mistakes

I learned that fast scans are not automatically good scans. Timeouts, blocked ports, and unreachable hosts can create false assumptions.

🌐 Packet-tracer-TEAM

Team lab
Goal

Practice network design and configuration in Cisco Packet Tracer while producing work that can be reviewed by teammates and instructors.

Learning

Network layout, device roles, addressing, routing concepts, documentation discipline, and how small configuration errors can break connectivity.

Strength

I am comfortable discussing the network troubleshooting process: isolate the layer, verify addressing, check interfaces, then test path behavior.

Mistakes

I learned to document assumptions earlier, label diagrams clearly, and verify connectivity step by step instead of changing too many things at once.

📋 NIST-CIS-CIA

Framework basics
Goal

Show that security is not only tools. It also requires controls, risk thinking, documentation, and business context.

Learning

NIST concepts, CIS controls, confidentiality, integrity, availability, and how frameworks guide technical priorities.

Strength

I can connect technical findings to risk language, which helps when documenting issues for managers, instructors, or Tier 2 teams.

Mistakes

I learned to avoid vague security wording and instead explain what is protected, what can fail, and what control helps reduce the risk.

🖥️ AD-max-Lab_Environment

Growing area
Goal

Build familiarity with Active Directory lab concepts for enterprise IT, identity, Windows administration, and security operations context.

Learning

Domain environment planning, user and system administration concepts, lab notes, and how identity infrastructure matters for SOC work.

Strength

This is an area I am actively developing. It connects my IT support background to real enterprise security workflows.

Mistakes

I learned that labs need clean setup notes, rollback planning, and careful documentation so the work can be repeated.
